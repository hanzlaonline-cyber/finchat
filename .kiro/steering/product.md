# FinChat — Product Overview

FinChat is an AI-powered personal finance management web app. It helps users track income and expenses, manage budgets and savings goals, and get conversational financial insights through an integrated AI chat interface.

## Core Features

- **Transaction Management** — Add expenses and income manually or via natural-language AI input. Supports split-bill tracking.
- **Dashboard** — KPI cards (balance, income, expenses, savings, health score) with trend charts and spending breakdowns.
- **Budgets** — Per-category monthly budget limits with spend tracking.
- **Goals** — Savings goals with target amounts, deadlines, and progress tracking.
- **Reports** — Spending trends and category breakdowns over configurable date ranges.
- **AI Chat** — Conversational assistant (Groq/LLaMA) that analyzes the user's actual financial data and answers questions.
- **AI Parse** — Natural language transaction entry that extracts structured transaction data from plain text.
- **Notifications** — Alerts for budget overruns, large transactions, and goal completions.

## Target Users

Individual users who want a single place to track spending, stay on budget, and get AI-driven guidance on their personal finances.

## Default Currency

PKR (Pakistani Rupee) — the default currency, with support for others. PKR and JPY/KRW are formatted with 0 decimal places.
